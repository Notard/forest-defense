# 플레이 기록 받기: 구글 시트 + Apps Script (16-4단계)

게임이 보내는 기록이 구글 시트 `plays` 탭에 한 줄씩 쌓이고, `summary` 탭에서 스테이지별로 묶어 본다.

## 처음 한 번 (사용자, 약 5분)

1. [구글 시트](https://sheets.new)에서 새 시트를 만든다. 이름은 예: `숲 지키기 기록`
2. 메뉴 **확장 프로그램 → Apps Script**
3. 왼쪽 `Code.gs`의 내용을 모두 지우고, 이 폴더의 [`Code.gs`](Code.gs)를 통째로 붙여 넣고 저장 (Ctrl+S)
4. 위쪽 함수 고르는 칸에서 **`setup`** 을 고르고 **실행** → 권한 요청이 뜨면 내 계정으로 허용
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동** (내가 만든 스크립트라 괜찮다)
   - 시트에 `plays`, `summary` 탭이 생기면 성공
5. 오른쪽 위 **배포 → 새 배포**
   - 유형 선택(톱니바퀴) → **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (게임이 로그인 없이 보내야 해서)
   - **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사
6. 그 주소를 브라우저에 붙여 넣어 `ok`가 보이면 준비 끝 → 주소를 알려 주면 `lib/game/telemetry.dart`의 `telemetryUrl`에 넣고 올린다

## 스크립트를 고친 뒤

**배포 → 배포 관리 → (연필) → 버전: 새 버전 → 배포**. 이렇게 하면 주소가 그대로다 ("새 배포"를 하면 주소가 바뀐다).

## 쌓이는 것 (`plays` 탭)

| 칸 | 뜻 |
|---|---|
| received | 시트가 받은 시각 |
| t | 기기 시각 (UTC) |
| event | `open` 앱을 켬 · `start` 판 시작 · `end` 판 끝 |
| id | 기기마다 무작위로 만든 번호 (이름·기기 정보 아님) |
| v · plat · lang | 게임 버전 · `web-android`, `web-ios`, `windows` … · `ko`/`en` |
| diff · stage | 난이도 · 스테이지 |
| result | `won` · `lost` · `quit-retry`(다시 하기) · `quit-map`(지도로) |
| sec · wave · hearts · defeated · stars | 실제로 판이 돈 초 · 웨이브 · 남은 하트 · 쓰러뜨린 수 · 별 |
| placed · levelups | 친구별로 놓은 수 (`fox:5,squirrel:2`) · 레벨업 수 |
| first | (`open`) 처음 켠 기기인지 |

`start`는 있는데 `end`가 없는 판은 창을 닫은 판이다.

## 주의

- 주소를 아는 누구나 줄을 보낼 수 있다 (게임 안에 주소가 들어 있으니까). 스크립트는 아는 사건(`open`·`start`·`end`)만, 4 KB 이하만, 칸마다 200자까지만 받는다. 이상한 줄이 많으면 배포를 새로 하고 주소를 바꾸면 된다
- 시트는 내 구글 드라이브에만 있다. 게임 쪽에서는 설정 창의 **기록 보내기 끄기**로 언제든 멈출 수 있고, 개인정보 처리방침(`web/privacy.html`)에 적혀 있다
